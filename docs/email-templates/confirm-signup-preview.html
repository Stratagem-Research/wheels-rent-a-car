Branded replacement for Supabase's default "Confirm signup" email — ink-and-signal-red identity, wordmark band, and a clear single CTA, matching the rest of Wheels.

01

Paste it into Supabase

  1. 1 Open your Supabase project → Authentication → Emails → Templates.
  2. 2 Select the Confirm signup template.
  3. 3 Replace the message body with the HTML below, then save. The {{ .ConfirmationURL }} and {{ .Email }} variables are Supabase's own — keep them exactly as written.
i This only changes the email's look. If confirmation emails aren't arriving at all, that's a separate Supabase SMTP/rate-limit setting — Authentication → Emails → SMTP Settings.
